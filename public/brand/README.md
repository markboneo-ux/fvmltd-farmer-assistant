# Farmersvaluemart brand assets

No official Farmersvaluemart / FVMLTD logo file was present in this repository
when the conversational assistant was branded.

Place the official logo here so the chat header can load it:

- `public/brand/farmersvaluemart-logo.svg` (preferred)
- or `public/brand/farmersvaluemart-logo.png`

Use the official artwork only. Do not substitute a redrawn mark.

The header component looks for those exact filenames and falls back to a
labeled empty slot if neither file exists.
