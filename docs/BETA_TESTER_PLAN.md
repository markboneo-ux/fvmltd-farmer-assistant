# Controlled beta tester plan

Start with **10–20 users**. Suggested mix:

- 5 home gardeners
- 10 commercial farmers
- 2–3 agronomists / technical users

Collect about **100–200 genuine conversations/cases** before a wider launch.

FVMLTD should give selected testers the promotional code **FVM** by hand. The code is validated only on the server.

## What to track

- Usefulness of guidance
- Diagnostic errors
- Photo success rate
- Repeat use
- Crop improvement (follow-up outcomes)
- Willingness to register
- Usage-limit conversion
- Upgrade clicks
- Promo-code use
- Willingness to pay

`/admin/insights` aggregates users, messages, cases, usage-limit events, upgrade clicks, promo redemptions, and agronomic patterns without exposing farmer identities.
